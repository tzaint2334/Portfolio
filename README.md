# 🎓 Guardian Institute Website

A modern, responsive, and visually appealing educational institute landing page built using **HTML5**, **CSS3**, and **JavaScript**. The project features a clean UI, glassmorphism navigation bar, smooth animations, responsive layout, and interactive hover effects.
